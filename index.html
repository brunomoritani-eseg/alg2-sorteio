Algoritmos 2
Sorteio do Projeto

Cada dupla receberá uma única questão. O enunciado não informa qual paradigma algorítmico deve ser utilizado: identificar e justificar a estratégia faz parte do projeto.

Dados da dupla

Preencha os dados abaixo. Ao continuar, o GitHub abrirá uma nova issue já preenchida. Basta revisar e clicar em Submit new issue.

Sorteio único por dupla. Depois que uma dupla recebe uma questão, novas solicitações com os mesmos RAs não geram outro sorteio.

Como funciona

  1. Você informa os integrantes da dupla nesta página.
  2. O site abre uma nova issue no GitHub com os dados já preenchidos.
  3. Você clica em Submit new issue.
  4. O GitHub Action processa o sorteio e responde na própria issue.
  5. A issue é fechada automaticamente após o resultado.
