# Alg2 Sorteio

Ambiente de testes do sorteador do projeto de Algoritmos 2.

Este repositório é público e contém apenas a interface dos alunos e o fluxo de solicitação de sorteio. O mapeamento entre questão e paradigma, o controle de distribuição e o histórico oficial ficam no repositório privado `alg2-sorteio-admin`.

## Estado atual

Ambiente de testes. Não use como sorteio oficial até a validação final.

## Fluxo

1. A dupla acessa a página.
2. Informa os dois RAs e nomes.
3. Abre uma solicitação de sorteio pelo GitHub.
4. O workflow valida se a dupla já sorteou.
5. A questão atribuída é registrada no repositório privado.
6. O resultado é publicado na própria solicitação.
